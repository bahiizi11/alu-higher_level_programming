# javascript-warm_up

Introductory JavaScript, run directly with Node.js: constants,
`process.argv`, type coercion, loops, recursion, and simple modules.

| File | Description |
|------|-------------|
| `0-javascript_is_amazing.js` | Prints a constant string |
| `1-multi_languages.js` | Prints three fixed lines |
| `2-arguments.js` | Reports how many arguments were passed |
| `3-value_argument.js` | Prints the first argument, without using `.length` |
| `4-concat.js` | Prints `<arg1> is <arg2>` |
| `5-to_integer.js` | Converts the first argument to an integer, or reports failure |
| `6-multi_languages_loop.js` | Same output as task 1, built with a loop and a single `console.log` |
| `7-multi_c.js` | Prints "C is fun" *x* times, from a loop |
| `8-square.js` | Prints an `X`-character square of a given size |
| `9-add.js` | Defines and uses `add(a, b)` on two arguments |
| `10-factorial.js` | Computes a factorial recursively |
| `11-second_biggest.js` | Finds the second-largest integer among the arguments |
| `12-object.js` | Mutates an object property without reassigning the `const` binding |
| `13-add.js` / `13-main.js` | An `add` function exported as a module, and a script that requires it |

## Usage

```bash
./0-javascript_is_amazing.js
```

## Requirements

- Node.js
- Scripts are executable (`chmod +x`) and start with `#!/usr/bin/node`
- Style-checked with `semistandard`
